# Student Application AI Helper

A free local-first helper for students who want their own AI agent to prepare applications and improve writing.

Open the website:

```text
https://jobmcp.pmlecuong.com/
```

Connection address for AI agents:

```text
https://jobmcp.pmlecuong.com/mcp
```

## What It Does

- sets up a local writing workspace
- gives starter files for CV and cover-letter work
- helps your local AI agent create application documents
- checks selected writing text for reader fit, tone, evidence, and convention problems
- supports application, academic, blog, work, social, and general writing modes

## What Stays Local

Keep these on your laptop:

- CV files
- profile notes
- job posts
- writing samples
- drafts
- generated PDFs
- final documents

Send only selected writing text to the checker when you want feedback.

## Start Prompt

```text
Set up my Student Application AI Helper workspace.
Use the service only for starter files, instructions, and selected writing checks.
Keep my CV, notes, job posts, drafts, and final documents on my laptop.
After setup, show me the folder I should fill and the next action.
```

## Writing Check Prompt

```text
Check the selected text with the writing checker.
Mode: application.
Tell me what sounds generic, unsupported, too polished, or unclear for a real reader.
Then revise the local draft without inventing facts.
```

For thesis, literature review, article, or class writing, change the mode to `academic`.

## Important Rule

The checker is not a promise to bypass AI detection. It is a writing-quality helper. It helps make text clearer, more specific, more convention-aware, and more trustworthy.
