# Fictional German Cover-letter Demo

This is a layout demonstration using generic placeholder **Jane Doe**, an anonymous fictional recruiting team, Stuttgart Hauptbahnhof as the non-residential location, and a deliberately invented signature graphic. Its writing is adapted from a candidate-authorized Mercedes-Benz application example, with personal identity details replaced. It is not a real person's signature and must not be reused as one.

The source draft is rendered by the same local LaTeX template distributed in the application kit. It demonstrates the familiar German business-letter structure: sender block, recipient block, date, bold subject, salutation, five evidence-based paragraphs, signature area, and enclosure list. The language should still match the actual role and employer.
