# Writing Mode Framework

Use the same underlying person, but change the surface style based on the artifact.

## Application Mode

Use for cover letters, recruiter emails, role-fit summaries, and interview follow-ups.

Preserve:
- real motivation
- contribution-oriented confidence
- verified evidence
- concise personal grounding

Suppress:
- blog-style reflection
- inflated claims
- generic enthusiasm
- unsupported seniority

Default shape:
1. why this role or message matters
2. what makes the fit credible
3. what evidence supports the fit
4. concise next step

## Academic Mode

Use for theses, research papers, literature reviews, methodology, and class submissions.

Preserve:
- problem framing
- logical structure
- evidence discipline
- honest limitations

Suppress:
- direct reader talk
- motivational language
- unsupported claims
- casual storytelling unless reflective practice is explicitly required

Default shape:
1. research question
2. gap or problem
3. method or approach
4. evidence and analysis
5. limitations
6. contribution and conclusion

## Work Mode

Use for meeting recaps, user stories, ticket descriptions, stakeholder updates, and operational notes.

Preserve:
- clarity
- actionability
- visible assumptions
- risks and blockers

Suppress:
- long personal stories
- recruiter polish
- academic heaviness
- emotional overstatement

Default shape:
1. context
2. current state
3. decision, ask, or blocker
4. next step

## Social Mode

Use for LinkedIn, Facebook, portfolio snippets, and content calendars.

Preserve:
- real trigger
- useful insight
- platform fit
- human but controlled tone

Suppress:
- fake creator hype
- unsupported trend claims
- direct translation between languages
- long-form blog sprawl

Default shape:
1. hook
2. context
3. insight or lesson
4. practical takeaway
5. optional question

## Personal Or Blog Mode

Use for reflective essays, personal technical writing, and learning-in-public posts.

Preserve:
- lived context
- tradeoffs
- failure and recovery
- visible thought process

Suppress:
- generic AI-blog openings
- fake authority
- over-polished corporate tone

Default shape:
1. real trigger
2. friction
3. attempt
4. result
5. lesson
6. what to do differently
