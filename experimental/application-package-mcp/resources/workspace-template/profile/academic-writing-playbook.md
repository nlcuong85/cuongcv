# Academic Writing Playbook

Use this for abstracts, thesis sections, literature reviews, and article paragraphs.

## Abstract Pattern

1. Problem and context.
2. Research purpose or question.
3. Data and method.
4. Main result.
5. Interpretation.
6. Practical or theoretical implication.
7. Limitation or boundary.

## Claim Discipline

- State what the data show.
- State what the method can support.
- State what remains uncertain.
- Do not hide limitations behind polished wording.
