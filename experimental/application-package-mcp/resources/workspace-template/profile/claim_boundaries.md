## Do Not Claim

Add claims the agent must not make unless the user updates the evidence.

- Advanced professional fluency in a language unless verified.
- Expert-level engineering ability unless verified by projects, work history, or code evidence.
- Leadership authority beyond documented roles.
- Certifications, grades, awards, or employment history not present in the profile.

## Evidence Rule

If a claim would make the person look more qualified, it needs evidence. If evidence is missing, use conservative wording or omit the claim.
