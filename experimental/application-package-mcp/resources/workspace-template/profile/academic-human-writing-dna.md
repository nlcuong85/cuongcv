# Academic Human Writing DNA

This file stores student-specific lessons about academic writing that sounds human while staying correct.

Prefer:

- direct topic sentences
- concrete data, sample, variable, or method details
- short limitation statements
- interpretation that follows from evidence

Avoid:

- ornamental academic phrases
- identical paragraph sizes
- long sentences that combine method, result, and implication
- adding fake mistakes to sound human

The private server checker gives selected-text feedback. Do not recreate or store its private rule logic here.
