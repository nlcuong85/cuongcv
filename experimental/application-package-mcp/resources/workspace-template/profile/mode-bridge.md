# Mode Bridge

The same student facts must be transformed differently depending on the writing mode.

## Application

Use role-specific motivation, verified evidence, and concise contribution language.

## Academic

Use precise claims, method boundaries, limitations, and evidence-first interpretation.

## Work

Use context, current state, blocker or decision, and next step.

## Social

Use one useful idea, a clear hook, and enough evidence to remain credible.

## Blog

Use a real trigger, friction, lesson, and practical reader value.
