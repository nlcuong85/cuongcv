# Academic Voice Bridge

Academic writing should be precise and restrained without becoming generic.

Preserve:

- clear problem framing
- readable cause-and-effect logic
- visible method and evidence
- honest limitation framing

Avoid:

- inflated novelty language
- vague phrases such as `robust framework` without detail
- claims stronger than the data can support
- casual blog voice
- detector-focused tricks that weaken academic correctness
